# External API Examples

Replace `https://YOUR-ENVIRONMENT-HOST` and `<your-api-key>` with your environment URL and owner API key.

## Create An Individual Customer

```bash
curl -X POST "https://YOUR-ENVIRONMENT-HOST/api/create-customer-profile" \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: <your-api-key>" \
  -d '{
    "customer_id": "EXT-CUST-1001",
    "first_name": "Ava",
    "last_name": "Patel",
    "date_of_birth": "1990-04-18",
    "email": "ava.patel@example.com",
    "phone": "+1-555-0100",
    "address": {
      "street": "100 Main Street",
      "city": "Toronto",
      "state": "ON",
      "country": "CA",
      "zip_code": "M5V 1A1"
    }
  }'
```

## Create A Main Account

```bash
curl -X POST "https://YOUR-ENVIRONMENT-HOST/api/create-main-account-external" \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: <your-api-key>" \
  -d '{
    "external_id": "MAIN-CASH",
    "main_account_name": "Cash",
    "main_account_code": "1000",
    "main_account_type": "Asset",
    "is_debit": true

```

## Retrieve An Order

```bash
curl -X GET "https://YOUR-ENVIRONMENT-HOST/api/retrieve-order?order_id=ORDER-5001" \
  -H "X-API-KEY: <your-api-key>"
```

## Create A Balanced Invoice

Each invoice must have at least two registers. Total `creditAmountLc` must equal total `debitAmountLc`.

```bash
curl -X POST "https://YOUR-ENVIRONMENT-HOST/api/create-invoice-external" \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: <your-api-key>" \
  -d '{
    "invoices": [{
      "invoiceId": "INV-9001",
      "invoiceDate": "2026-08-23",
      "invoiceType": "Cash",
      "branchId": "TOR",
      "customerId": "EXT-CUST-1001",
      "registers": [
        {
          "methodOfPayment": "Cash",
          "type": "Debit",
          "accountId": "CAD-CASH-001",
          "currency": "CAD",
          "rate": 1,
          "inAmount": 100,
          "creditAmountLc": 0,
          "debitAmountLc": 100
        },
        {
          "methodOfPayment": "Cash",
          "type": "Credit",
          "accountId": "USD-CASH-001",
          "currency": "USD",
          "rate": 1.34,
          "outAmount": 74.63,
          "creditAmountLc": 100,
          "debitAmountLc": 0
        }
      ]
    }]
  }'
```
